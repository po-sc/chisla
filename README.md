# chisla

Учебный проект на Java — работа с числами и числовыми алгоритмами.

## Содержимое

- `src/Main.java` — основная программа
- `src/MainTest.java` — тесты
- `src/numbers.txt` — входные данные

## Технологии

- **Java**
- **IntelliJ IDEA**

## Запуск

Открыть проект в IntelliJ IDEA и запустить `Main.java`.
